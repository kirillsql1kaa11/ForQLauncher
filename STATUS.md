# ForQ Launcher — статус проекта

Дата остановки: 22.10.2026. Лаунчер Minecraft для личного использования: оффлайн-вход,
установка модов/ресурспаков/шейдеров с Modrinth, версии 1.20.1 / 1.16.5 / 1.12.2,
загрузчики Fabric / Quilt / NeoForge.

### Известные особенности, выясненные при разведке

- **1.12.2** не имеет секции `arguments` в манифесте — используются хардкод-аргументы
  старого формата (`--username/--version/--gameDir/...`).
- **1.12.2 и 1.16.5** используют старый формат нативов (`natives` + `classifiers`),
  распаковка делает лаунчером. **1.20.1** — нативы внутри основного jar, распаковывает LWJGL сам.
- Плейсхолдеры вида `${quickPlayPath}` выключаются через `features`-правила
  (`has_quick_plays_support` и т.п.), их надо считать выключенными, иначе игра падает
  с `AccessDeniedException` на каталог игры.
- **Fabric для 1.12.2 недоступен**: fabricmc.net больше не отдаёт `intermediary` для 1.12.2,
  meta API возвращает пустой список лоадеров. 1.12.2 = только vanilla.
- **Quilt не поддерживает 1.12.2/1.16.x ниже 1.14** — только 1.14+.
- **NeoForge не поддерживает 1.20.1** — начал с 1.20.2. Правило соответствия:
  MC `1.20.z` → линия `20.z`, MC `1.21.z` → линия `21.z`, MC `26.z` → линия `26.z`.
  Таблица проверена по `install_profile.json` внутри установщика.
- Установщику NeoForge нужен файл `launcher_profiles.json` в каталоге инстанса
  (иначе «There is no minecraft launcher profile…»). Уже создаётся лаунчером.
- Сборка NeoForge может быть рассчитана на другую версию MC, чем выбрал пользователь
  (например, 21.1.264 → 1.21.1). Инстанс сам подстраивается: `inheritsFrom` читается из
  созданного профиля, версия MC в инстансе обновляется, ассеты докачиваются.

## Что НЕ сделано

1. **GUI (`src/ForQ.App`)** — сгенерирован шаблоном Avalonia 12.1.4, `MainWindow` пустой.
   Весь функционал есть в Core, но экранов нет. Это главный объём работы на следующий заход:
   - выбор/создание инстанса (версия MC + загрузчик + версия загрузчика)
   - вкладка «Игра»: ник, память, кнопка «Играть», лог
   - вкладка «Контент»: поиск по Modrinth, фильтр (моды/ресурспаки/шейдеры), установка,
     список установленного с вкл/выкл
   - вкладка «Настройки»: телеметрия, путь к Java, папка с данными
2. **Modrinth не покрыт из UI** — Core-методы есть, но не подключены к кнопкам.
   Формат фасетов проверен вручную: `[["project_type:mod"],["versions:1.20.1"],["categories:fabric"]]`
   (для ресурспаков и шейдеров `categories` не передаётся, загрузчик = null).
   Фильтр по версии MC и загрузчику нужно брать из выбранного инстанса.
4. **Скины** — не реализовано (пользователь отказался от этой функции, нужен был только оффлайн-вход).
5. **Список версий MC** — в UI нужно ограничить 1.20.1/1.16.5/1.12.2 (или показывать все релизы).
6. **Нет git-репозитория** — папка не под контролем версий.

```

  Directory.Build.props      сборка выносится в %LOCALAPPDATA%\ForQLauncher\build (чистка OneDrive)
  ForQLauncher.slnx          .NET 10 SDK, формат slnx
  src/ForQ.Core/             логика (без UI, без сторонних пакетов)
    Models.cs                DTO Mojang/Modrinth
    Domain.cs                Instance, AppSettings, LoaderKind, ContentKind
    HttpApi.cs               HTTP + скачивание с проверкой SHA1 + распаковка jar
    DownloadManager.cs       параллельные загрузки
    MojangService.cs         манифест, версии, ассеты, рантайм Java
    LibraryResolver.cs       правила os/features, пути библиотек, нативы
    LoaderService.cs         Fabric / Quilt / NeoForge
    ModrinthService.cs       поиск и версии Modrinth
    ContentService.cs        установка контента, options.txt
    GameOptions.cs           чтение/запись options.txt
    GameInstaller.cs         установка игры и загрузчиков
    LaunchService.cs         цепочка версий, аргументы, запуск процесса
    InstanceService.cs       инстансы и настройки
    ProcessRunner.cs         запуск внешних процессов
  src/ForQ.App/              Avalonia 12.1.4 (GUI ещё не написана)
  tools/ForQ.Smoke/          консольный стенд: установка + запуск + печать плана запуска
```

## Как запускать проверку

```powershell
dotnet run --project tools/ForQ.Smoke/ForQ.Smoke.csproj -c Release -- --mc 1.20.1 --loader fabric --launch
```

Флаги: `--mc`, `--loader` (vanilla|fabric|quilt|neoforge), `--loader-version`, `--root`, `--launch`.
Стенд качает игру в `%TEMP%\forq-smoke` (4,5 ГБ: 1.12.2, 1.16.5, 1.20.1, 1.20.2+NeoForge).
Инстанс переиспользуется между прогонами по имени `smoke-<mc>-<loader>`, повторный прогон быстрый.
Стенд можно удалить без риска для проекта.
