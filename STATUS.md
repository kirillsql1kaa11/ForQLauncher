# ForQ Launcher — статус проекта

Дата: 22.10.2026. Лаунчер Minecraft для личного использования: оффлайн-вход,
установка модов/ресурспаков/шейдеров с Modrinth, версии 1.20.1 / 1.16.5 / 1.12.2,
загрузчики Fabric / Quilt / NeoForge.

## Версия 1.3.0 (22.10.2026)

- **Отметки «Установлено» в поиске.** Для каждого результата проверяется `content.json`
  профиля: проект считается установленным, только если запись нужного типа есть и файл
  (включая `.disabled`) реально лежит в папке. Вместо «Установить» показывается
  неактивная кнопка «Установлено», повторная установка из списка недоступна. Отметки
  обновляются после установки, установки из карточки и удаления. Проверено в живом окне
  на профиле `78t`: Fabric API, Iris Shaders и Sodium помечены, остальные — «Установить».
- **Пагинация до 500.** Поиск запрашивает по 100 результатов (лимит Modrinth) и
  добавляет страницы кнопкой «Показать ещё · N из 500»; после 500 кнопка исчезает,
  в счётчике — «17762 проектов · первые 500». То же для модпаков. Проверено: пять
  страниц, 500 уникальных проектов, счётчики и скрытие кнопки работают.
- **Удаление установленного.** В панели «Установлено» появилась кнопка «Удалить»:
  первый клик меняет её на «Точно?», второй удаляет файл, запись `content.json` и
  убирает ресурспак из `packs` в `options.txt`; активный шейдер сбрасывается. Проверено
  тестовым модом в `78t`: файл и запись удалены, список обновился, отметка в поиске
  снялась. Данные профиля восстановлены после проверки.
- **Сетевые сбои и SSL.** Ошибка `The SSL connection could not be established` на
  NeoForge 1.21.11 не воспроизвелась: `BuildPlanAsync` для профиля `123-33944f`
  (1.21.11, NeoForge 21.11.48) проходит, установщик в логе завершился успешно, Java 21
  и все библиотеки на месте. В `HttpApi` добавлены три попытки для TLS/сетевых ошибок,
  таймаутов, 408/429/5xx с паузами 400/800 мс; частично скачанный файл удаляется перед
  повтором, а текст ошибки теперь содержит URL проблемного запроса.
- **Ещё 30 идей.** В `ROADMAP.md` добавлены пункты 31–60.

## Версия 1.2.0 (22.10.2026)

Добавлено и проверено в живом окне:

- **Обновление модов в один клик.** «Контент» → «Обновления»: файлы опознаются по SHA-1
  через bulk-эндпоинты Modrinth (`/version_files`, `/version_files/update`), для устаревших
  появляется «Обновить» и «Обновить все». Проверено на Sodium 0.5.11 → 0.5.13: старый файл
  удалён, новый скачан, статус «Обновлено: Sodium → mc1.20.1-0.5.13-fabric».
- **Карточки контента.** Отдельное окно: иконка, обложка, перевод описания на русский,
  зависимости, похожие проекты, версия и размер, установка. Проверено на Fabric API
  (перевод, «Нет обязательных зависимостей», четыре похожих проекта). Для модпаков блок
  зависимостей заменён пояснением.
- **Модпаки.** Вкладка с поиском Modrinth и установкой `.mrpack`: создаётся профиль,
  ставятся игра и загрузчик, качаются файлы сборки, распаковываются `overrides/` и
  `client-overrides/`. Проверено на Simply Optimized Reloaded (1.20.1, Quilt 0.29.1):
  17 модов, 12 конфигов, `lang:ru_ru`. При отмене или ошибке профиль удаляется.
- **Автоподбор памяти.** Четверть ОЗУ, округление до 512 МБ, диапазон 2–8 ГБ; кнопка
  «Подобрать». На машине с 16 ГБ рекомендует 3584 МБ.
- **Автообновление лаунчера.** Проверка `releases/latest` на GitHub, баннер, скачивание
  и подмена exe через `.cmd` с перезапуском; токен для приватного репозитория — в «Настройках».
- **Русский язык игры.** Новому профилю (в том числе модпаку) сразу пишется `lang:ru_ru`.
- **Поиск без кнопки.** При открытии вкладки, смене сегмента и профиля поиск идёт сам;
  для Fabric-профиля — только совместимое, с подписью «Только совместимое с 1.20.1 · Fabric».

## Что сделано и проверено

### Полный цикл в GUI — пройден end-to-end

Создание профиля (1.20.1 + Fabric) → скачивание игры → установка загрузчика →
поиск по Modrinth → установка мода (Fabric API) → запуск игры с модом.
По логам игры: `Loading Minecraft 1.20.1 with Fabric Loader 0.19.5` и
`fabric-api 0.92.12+1.20.1` со всеми модулями.

Ресурспак ставится в `resourcepacks/` и включается в `options.txt`
(`packs:["file/..."]`), шейдер — в `shaderpacks/` (`shaderPack:"..."`).

### Известные особенности, выясненные при разведке

- **1.12.2** не имеет секции `arguments` в манифесте — используются хардкод-аргументы
  старого формата (`--username/--version/--gameDir/...`).
- **1.12.2 и 1.16.5** используют старый формат нативов (`natives` + `classifiers`),
  распаковка делает лаунчером. **1.20.1** — нативы внутри основного jar, распаковывает LWJGL сам.
- Плейсхолдеры вида `${quickPlayPath}` выключаются через `features`-правила
  (`has_quick_plays_support` и т.п.), их надо считать выключенными, иначе игра падает
  с `AccessDeniedException` на каталог игры.
- **Fabric для 1.12.2 недоступен**: fabricmc.net больше не отдаёт `intermediary` для 1.12.2,
  meta API возвращает пустой список лоадеров. 1.12.2 = только vanilla.
- **Quilt не поддерживает 1.12.2/1.16.x ниже 1.14** — только 1.14+.
- **NeoForge не поддерживает 1.20.1** — начал с 1.20.2. Правило соответствия:
  MC `1.20.z` → линия `20.z`, MC `1.21.z` → линия `21.z`, MC `26.z` → линия `26.z`.
  Таблица проверена по `install_profile.json` внутри установщика.
- Установщику NeoForge нужен файл `launcher_profiles.json` в каталоге инстанса
  (иначе «There is no minecraft launcher profile…»). Уже создаётся лаунчером.
- Сборка NeoForge может быть рассчитана на другую версию MC, чем выбрал пользователь
  (например, 21.1.264 → 1.21.1). Инстанс сам подстраивается: `inheritsFrom` читается из
  созданного профиля, версия MC в инстансе обновляется, ассеты докачиваются.
- **Библиотеки и ассеты лежат в общем складе** `%APPDATA%\ForQLauncher\shared`
  (`libraries` и `assets`), второй профиль той же версии скачивает только клиентский jar
  и загрузчик. Нативы распаковываются в инстанс, моды/ресурспаки/шейдеры — тоже в инстанс.

## Что НЕ сделано

1. **Скины** — не реализовано (пользователь отказался от этой функции, нужен был только оффлайн-вход).
2. **Автообновление требует токена** — репозиторий приватный, без токена GitHub не отдаёт
   релиз; токен вводится в «Настройках» и хранится в `settings.json`. Установщика нет:
   exe собирается вручную.
3. **Формат фасетов Modrinth**: `[["project_type:mod"],["versions:1.20.1"],["categories:fabric"]]`
   (для ресурспаков и шейдеров `categories` не передаётся, загрузчик = null).
   В ответе поиска идентификатор проекта лежит в поле `project_id`, а не `id`
   (учтено в `ModrinthProject.Key`).
4. **Моды без загрузчика** — для ванильного профиля поиск модов отключён с подсказкой:
   Fabric/Quilt/NeoForge обязательны.
5. **Шейдеры без Iris/OptiFine** — файл кладётся и прописывается в `options.txt`,
   но в игре работать будет только при наличии мода-загрузчика шейдеров.

### GUI (`src/ForQ.App`) — готово

Тёмная тема в `Themes/Dark.axaml` (свои ControlTheme для Button, TextBox, ComboBox, ListBox,
TabControl, TabItem, CheckBox; акцент — зелёный #5DBB63).

Экраны:
- левая колонка — список профилей, кнопка «+ Новый профиль»;
- шапка — ник и кнопка «Играть», баннер доступного обновления лаунчера;
- вкладка «Игра» — память (слайдер) и кнопка «Подобрать», разрешение, профиль, журнал,
  остановка игры, очистка журнала;
- вкладка «Контент» — моды/ресурспаки/шейдеры, поиск по Modrinth с авто-запуском и подписью
  фильтра, результаты с иконками, «Установлено» для уже стоящих проектов, «Показать ещё»
  до 500, установленное с чекбоксами включения, удалением, «Обновления» и «Обновить все»,
  карточка проекта;
- вкладка «Модпаки» — поиск сборок и установка `.mrpack` в новый профиль;
- вкладка «Настройки» — ник, телеметрия, свой Java, папка данных, потоки загрузки, токен
  GitHub, авто-проверка обновлений, ручная проверка;
- диалог «Новый профиль» — версия Minecraft (избранные 1.20.1/1.16.5/1.12.2 первыми),
  загрузчик модов, версия загрузчика (подгружается по API), установка с оверлеем прогресса;
- окно карточки — иконка, обложка, перевод, зависимости, похожие, установка.

Проверено в живом окне: старт, профили, авто-поиск модов (17762) и ресурспаков (17747),
фильтр Fabric, иконки, переключение чекбоксов, карточка Fabric API с переводом, обновление
Sodium, старт установки модпака из карточки, полная установка Simply Optimized Reloaded,
автопамять, русский `options.txt`, отметки «Установлено», пять страниц по 100 и удаление
тестового мода с подтверждением. Скриншоты снимались через PrintWindow.

## Сборка .exe

```powershell
dotnet publish src/ForQ.App/ForQ.App.csproj -c Release -r win-x64 --self-contained true -o "$env:LOCALAPPDATA\ForQLauncher\publish"
Copy-Item "$env:LOCALAPPDATA\ForQLauncher\publish\ForQ.App.exe" "dist\ForQLauncher.exe" -Force
```

Не передавать `-p:AssemblyName=ForQLauncher`: свойство применяется ко всем проектам графа
и падает с `Ambiguous project name 'ForQLauncher'`. Переименование после публикации надёжнее.

Готовый файл лежит в `dist/ForQLauncher.exe` (~45 МБ, со встроенным .NET и иконкой),
ярлык на рабочем столе ведёт туда. Данные лаунчера и профили — в `%APPDATA%\ForQLauncher`.

## Как запускать проверку

```powershell
dotnet run --project tools/ForQ.Smoke/ForQ.Smoke.csproj -c Release -- --mc 1.20.1 --loader fabric --launch
```

Флаги: `--mc`, `--loader` (vanilla|fabric|quilt|neoforge), `--loader-version`, `--root`, `--launch`.
Стенд качает игру в `%TEMP%\forq-smoke` (4,5 ГБ: 1.12.2, 1.16.5, 1.20.1, 1.20.2+NeoForge).
Инстанс переиспользуется между прогонами по имени `smoke-<mc>-<loader>`, повторный прогон быстрый.
Стенд можно удалить без риска для проекта.
